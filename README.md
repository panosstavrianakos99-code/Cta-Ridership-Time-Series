# Chicago Transit Ridership: Time-Series Forecast

An R analysis of daily Chicago Transit Authority ridership, comparing bus, rail, and total rides and forecasting March ridership using time-series methods with a COVID-era indicator.

## Contents

- `ridership_forecasting.R` — analysis script.

## Data and reproducibility

The CTA CSVs and submitted reports are not included.
